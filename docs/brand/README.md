# BetterYears Age brand assets

The bird is the team's logo. It is drawn in the Dusk palette (peach `#FBDAB4`, cream, tan `#D8AB8B`, slate beak and legs), so it sits on Dusk charcoal glass as is. Never tint, recolor or outline it.

| File | Use |
|---|---|
| `betteryears-logo.png` | Original as shared (1024 x 853, transparent) |
| `betteryears-mark-512.png` | Trimmed mark for docs, README and slides |
| `app-icon-1024.png` | Flattened preview of the visionOS app icon (bird on Dusk charcoal `#252322`) |
| `sundai-card-thumbnail.png` | 1200 x 630 thumbnail for the Sundai project card |

In the app, the same mark ships as the `BrandMark` image and the `AppIcon` layered icon in `apps/vision/SpatialAge/Sources/Assets.xcassets`:
- **App icon layers:** the bird is on the front layer, the middle layer is empty, and the back layer is solid charcoal.
- **`BrandMark`:** this view draws the bird above the BETTERYEARS AGE label on the intro and Home screens.
- **Dashboard:** it shows the bird in its header and favicon.
