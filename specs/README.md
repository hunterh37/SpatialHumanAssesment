Spec index. Each spec states inputs, outputs and done criteria for one area.

- `architecture.md` components and data flow
- `session-schema.md` the session file contract
- `tasks/simple-reaction.md`, `tasks/choice-reaction.md`, `tasks/corsi-3d.md` task rules
- `features.md` feature definitions
- `age-model.md` functional age model and evaluation
- `dashboard.md` audience view

Open questions go at the bottom of the relevant spec under "Open".

`games/` one spec per minigame plus `design.md` for the shared design system. `score.md` for ScoreKit.
