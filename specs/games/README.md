# Games

The catalog follows the Games Ideas deck (feedback PDF, five slides). `Game.catalog` lists them in deck order. Raw values and task kinds predate the deck and stay fixed so stored sessions keep scoring.

| Deck game | `Game` | Task | Spec | Tests |
|---|---|---|---|---|
| Stick Drop | `pendulum` | `pendulum` | `pendulum.md` | visual to action reaction time, useful field of view |
| Spatial Memory | `dots` | `color_dots` | `color-dots.md` | decision time, spatial memory |
| Scary Balance | `reach` | `reach_grab` | `reach-grab.md` | reach and lean, holding a position, shaking |
| Hole in the Wall | `wall` | `wall` | `wall.md` | mobility, poses the participant cannot hit |
| Spatial Tracking | `spark` | `simple_rt` | `spark.md` | audio and visual to action reaction time, localization |

Gate, Constellation and Orbit are outside the deck. They still run and score when queued, and the catalog does not list them.

Backdrops: Stick Drop and Spatial Tracking play in a forest clearing (`Scenery.forest`), Hole in the Wall on a stone island inside a moat in the same clearing (`Scenery.moat`). Spatial Memory and Scary Balance keep the ink stage. Nothing in a backdrop moves.
